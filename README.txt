Budget Tracker v3 - Carryover

New feature: unused monthly budget automatically accumulates into a separate Carryover balance when a new month begins. If spending goes above the current month's budget, Carryover is used automatically. Monthly Remaining and Carryover stay displayed separately, and Total Available shows both together.

Existing transactions and the saved monthly budget remain compatible because the app continues using the same localStorage keys.

To update GitHub Pages, replace index.html, sw.js, manifest.webmanifest, and README.txt in the repository root. After GitHub Pages redeploys, fully close and reopen the Home Screen app/Safari page. If the old version appears briefly, refresh once.
