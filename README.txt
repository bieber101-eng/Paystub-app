Paycheck Estimator — iPhone Installable Web App

This is a Progressive Web App (PWA), not an App Store package. It works offline
after installation and appears on the iPhone Home Screen like a normal app.

To install on iPhone:
1. Upload this folder to any HTTPS web host, such as GitHub Pages, Netlify, or Cloudflare Pages.
2. Open the resulting website in Safari on the iPhone.
3. Tap Share.
4. Tap Add to Home Screen.
5. Name it Paycheck and tap Add.

The app saves your preferred defaults locally on the device.
